# CoHeRe — logo

**CoHeRe** · Computational Health Researchers · the graduate student association
of the joint UC Berkeley–UCSF PhD program.

The name is built from three syllables, each in its own colour, telling the story:

- **Co** — *Computation* — in **Berkeley Blue**
- **He** — *Health* — in **UCSF Teal**
- **Re** — *Researchers* (us) — in **gold**, for the Golden Bears

Set in Poppins Bold, with a California-gold rule over the tagline. Prefer the SVGs;
they stay sharp at any size.

## Colours

| Name | Hex | Where |
|---|---|---|
| Berkeley Blue | `#003262` | **Co** |
| UCSF Teal | `#18A3AC` | **He** |
| Deep gold | `#A87900` | **Re** (legible gold) |
| California Gold | `#FDB515` | the rule beneath the wordmark |
| Ink black | `#1b1b1a` | the tagline |

On dark backgrounds the "Co" lightens to `#3B7EA1` and the "Re" brightens to
California Gold `#FDB515` so both stay vivid.

The same folder mirrors these as high-resolution PNGs (on-dark files have the dark
background baked in). `docs/assets/images/` holds the browser-tab and phone icons.

The site uses `cohere-mark.svg` as the header logo and renders the **CoHeRe**
wordmark as live tri-coloured text — see the brand block at the top of
`docs/assets/stylesheets/extra.css` if you need to adjust it.

## Type

**Poppins Bold** (Google Fonts, Open Font License — free for any use). The letters
are outlined here, so nothing depends on the font being installed. To rebuild from
live text, use Poppins Bold and colour Co `#003262`, He `#18A3AC`, Re `#A87900`.

## Using it well

Keep clear space around the logo at least the height of the "o". Don't stretch it,
change the font, recolour the syllables, or add effects — start from these files if
you need a change. It stays legible to about 90px wide; the square mark holds to
16px. It uses the official Berkeley and UCSF colours, so keep it distinct from the
universities' own logos rather than presenting it as one.
